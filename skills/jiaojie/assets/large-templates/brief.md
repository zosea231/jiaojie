# 全局目标与路线

项目模式：large。读取顺序：根 AGENTS.md → 本文 → plan 概览 → index → 当前 workflow 的 brief／plan；跨任务按链接补读。

## 共同目标与阶段

填写项目目标、核心路线和当前阶段，保持稳定。

## 共享约束

只写影响所有工作流的范围、资源及重要问题入口。局部目标和实现细节在 `.ai/workflows/<workflow>/` 维护。

## 交付与协作

全局 plan 每条 workflow 保留简短结果、下一步与真实依赖；index 导航到局部文档、代码和证据。目录、worktree 与跨分支读取见 [架构说明](../references/project-architecture.md)。角色及是否并行由用户安排。
